# 『今昔マップ on the web』の使用上の注意と、今回の用途に照らした確認

確認日 **2026-08-27**。原本は https://ktgis.net/kjmapw/note.html
（時系列地形図閲覧サイト「今昔マップ on the web」使用上の注意／埼玉大学教育学部　谷 謙二）。

**結論：今回の使い方は、規約が明示的に認めている形である。** 禁止事項のどれにも触れていない。

CLAUDE.md は企画の初期に「今昔マップは著作権面の懸念があり保留」と書いていたが、
**それは規約を読む前の警戒であって、規約そのものは条件つきで公開を認めている。**

## 何に使っているか

絶景掲示板の時間軸、地物「愛宕山の採石場」の説明文に付く**図1**
（`assets/choshi/essay/quarry-fig1.webp`）。1972〜1982年の旧版地形図と現在の地理院地図を
左右に並べた画面のスクリーンショットで、採石場に赤丸が書き加えてある。
非営利の学生作品で、GitHub Pages で公開している。

## 規約の逐条チェック

| 規約の条項（要旨） | 今回 | 根拠 |
|---|---|---|
| 画像ファイル**自体**を複製してPC・サーバに保存する使い方はしない | **触れない** | 保存しているのは画面のスクリーンショットで、タイル画像ファイルではない。スクリーンショットの公開は下の「ネット上での使用について」が別に認めている |
| 地図タイル画像を複製して別サーバに置き**独自に配信**することを禁止 | **触れない** | 配信していない |
| Web・SNSで公開する場合は出典を付記（連絡不要） | **満たす** | キャプションに「『今昔マップ on the web』を一部改変して作成」（元の文章のまま）。規約の簡略版「「今昔マップ on the web」より作成」に相当 |
| **ロゴ入りスクリーンショットなら記述を省略できる** | **満たす（二重）** | 左上のロゴを消さずに切り出してある。**ロゴを消さないこと** |
| 可能であればURLのリンクを付ける | **満たす** | 図の下に https://ktgis.net/kjmapw/ へのリンクを置いた |
| 多数のアクセス（1000PV/日超）のページでは**埋め込み参照**をしない | **触れない** | 埋め込みではなく静止画。ADR-0001「画面からタイルサーバーを直接叩かない」と同じ向き |
| 精度が必要なら地理院から謄本交付を受けること | 該当なし | 位置の主張には使っていない（地物の座標は満願寺のもの。`confidence: approximate`） |
| 論文の場合は谷謙二(2017)を参考文献に | 任意 | 作品であって論文ではない。図の「出どころ」欄に (C)谷 謙二 を明記している |

## 国土地理院の側（測量法29条・30条）

規約に「本サイトの地図画像を使用した場合でも、国土地理院長の承認を得る必要があるケースがある」
とある。地理院の[測量成果の利用手続](https://www.gsi.go.jp/LAW/2930-index.html)を確認した。

- **旧版地図（陸地測量標条例制定以降）も対象**と明記されている。
- ただし**出典を明示すれば申請が不要**となる場合があり、書籍の挿入図・ウェブサイトへの
  地図の挿入などが例に挙がっている。
- 加工した場合の出典の書き方として、[出典の記載](https://www.gsi.go.jp/LAW/2930-meizi.html)に
  **「地理院タイルに○○を追記して掲載」**が例示されている。**印を書き加えること自体は、
  出典明示の範囲で扱われている。**
- 同ページの「**編集・加工した情報を、あたかも国土地理院が作成したかのような態様で公表・
  利用しないでください**」に従い、図の「出どころ」には**赤丸が作成者の追記であること**を書いた。

**残る不確かさ**：赤丸の追記が29条でいう「独自情報の付加」にあたり承認申請が要るのか、
出典明示で足りるのかを、地理院に直接確かめてはいない。**図を外すことになっても作品は
崩れない**ようにしてある（下）ので、応募までに問い合わせが間に合わなくても止まらない。

## 外すことになった場合

図は `data/choshi/timeline.json` の `quarry` → `essay.figure` **1か所だけ**にある。
そこを消せば画面から消える（`tools/build-board.js` で作り直す）。

同じ範囲の**国土地理院の空中写真**（1974〜1978年撮影／2007年以降）を
`assets/choshi/timeline/quarry-*.webp` に別途置いてあり、**1974〜78年の写真には削られた
斜面が白く写り、現在の写真では同じ場所に満願寺が建っている。** 図1が見せたかったこと
（採石場跡＝満願寺）は、そちらでも見える。

## やってはいけないこと

- **ロゴを消して切り出し直さない。** 消すと出典表記の省略条件を失う。
- **タイル画像を直接ダウンロードして配信しない**（ADR-0001・ADR-0003 とも一致）。
- **`<iframe>` や画像の直リンクで今昔マップを埋め込まない。**
- この図を使って**販売**をしない。
