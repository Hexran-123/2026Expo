# 絶景掲示板 設計メモ

沿線だけでなく銚子エリア全体の絶景スポットを扱う、もう一つの掲示板的ウェブサイト。パソコン専用・横構図。
既存の「車窓絶景ナビ」（[設計書.md](設計書.md)、銚子電鉄沿線限定）とは別画面として作る。応募作品の一部。

まだ実装には着手していない。この文書は、Claude Artifact上での試作とPlaywrightでの動作確認を重ねて
決めた内容の記録。**実装に進む前に必ず参照すること。**

---

## 1. 全体の機能（決定済み・実装はこれから）

- 目的: 旅行前にどこにどんな絶景スポットがあるかを知らせる。
- 一番大事な画面: 斜め視点の2D地図。地図上にピンを刺し、タップすると右側にその場所の写真パネルが出る
  （コメント形式）。
- 投稿: 本物の投稿機能を作る（誰でも写真を投稿できる）。事前審査あり。サイト内にパスワードで保護した
  簡易審査ページを作る。
- ピン配置: 地図上の任意の位置に自由に落とす。近いピンは自動でクラスター化し、件数バッジを出す。
- 画像利用: 銚子市観光協会フォトダウンロードの許諾条件に従う
  （[docs/銚子市観光協会フォトダウンロード利用規約.md](銚子市観光協会フォトダウンロード利用規約.md)参照。
  直リンク禁止、ローカル保存、クレジット表記必須、商用不可）。
- データ保持: 投稿は ADR-0004 の削除タイミング（2027-04-30 一括削除）に合わせる。
- 累積人気: 既存の「いいね」の仕組み（IPハッシュ）を流用する。
- 導線: トップページに新規リンク「絶景掲示板」（例: `board.html`）を追加する。
- モバイル: 画面幅が狭いときは地図を閉じ、案内ページのみを表示する（PC専用機能のため）。
- GPS: ユーザーのGPSを読み取り、位置入力の補助として使う。

## 3. 地図画面の見た目（この会話のプロトタイプで決定）

- **背景**: 実データの地形（国土地理院DEMから実際に取得・生成した等高線バンド）を流用する。
  既存の `data/choshi/terrain.json` は沿線周辺だけしかカバーしていないため、本銚子〜松岸まで含むよう
  範囲を広げて `tools/fetch-elevation.js` → `tools/build-terrain.js` と同じ手順で再生成する。
- **表現形式**: 色分け段彩図（設計書 5.2 と同じ配色・考え方）はそのまま踏襲しつつ、CSSの3D変形で
  斜め視点にする。平面的な地図という既存方針（ADR-0001）の例外として、この掲示板画面だけ立体で見せる。
- **地形の誇張度**: 標高 × 1.2倍。（最初 × 2.4倍を試したが「あらゆるものが浮いて見える」との指摘で
  控えめに調整した。）
- **操作**: Googleマップ風。ドラッグで移動、Ctrl+ドラッグ（または右ドラッグ）で回転・傾き、
  ホイールで拡大縮小。範囲はズーム0.5〜4倍、傾き15°〜70°。
- **ピン**: 地図アプリ風の刺さるピン＋四角い写真（丸ではなく四角）。近接ピンは自動クラスター化し、
  件数バッジを出す。
- **写真パネル**: 初期画面は地図のみで、パネルは非表示。ピンをタップすると地図が縮小しながら
  右からパネルがスライドインする。地図の何もないところをタップすると、パネルが閉じて元の状態に戻る。
  クラスターで複数件あるときは、各カードの左上にそのスポット名を表示する。公式提供かどうかは
  地図上のピンではなく、パネル内の各カードのバッジで示す。
- **駅名ラベル**: ビルボード方式（地図を回転させても常に読める向きを保つ）。文字の背景（灰色の四角）は
  置かず、白い縁取りだけで視認性を確保する。
- **線路の高さ表現**: 「駅を通る滑らかな曲線」を採用。Catmull-Romスプラインで各駅の実測標高
  （国土地理院DEMを実際にサンプリングした値）を正確に通り、駅間は滑らかに補間する。
  **線路の縁取り（白いハロー）はなし。** 比較のうえ「圧倒的にこちらが良い」との判断による。
  検討した他の案（駅ごとに一段ずつ変える階段状、実測標高を軽く／しっかり均しただけの坂、
  線路自体は平坦にして駅だけ支柱で高さを示す方式）は不採用。
