# 地図はタイルを使わず自作イラストとする

地理院地図などの地図タイルをそのまま背景に用いると情報量が多すぎ、車内で一瞬見るには読み取れない。一方で位置の正確さは審査観点「地理空間情報の活用」に直結するため捨てられない。そこで、路線・駅の座標と標高は実データを骨格として用いつつ、画面に出る絵はゲームの世界地図のようなイラストとして描き起こすことにした。測量的な精度ではなく「どこに何があり、どちらが高いか」という空間の直感を伝えることを目的とする。

## Consequences

- 地図ライブラリのタイル表示機能は使わず、SVG に自作の地形レイヤーとアイコンレイヤーを重ねる構成になる。
- 緯度経度から画面座標への変換は自前で行う。銚子電鉄の全長は約 6.4km と狭いため、単純な線形変換で実用上の精度が出る。
- 路線を増やす場合は、そのたびに地図イラストを描き起こす必要がある。この負荷は [将来構想](../将来構想.md) のプラットフォーム化の障壁として認識しておく。
