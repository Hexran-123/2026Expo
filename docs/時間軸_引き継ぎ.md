## 触る前に、これだけは

1. **`board.html` を直接編集しない。** 直すのは `tools/board-template.html`。
2. **`data/choshi/timeline.json` に、出典の無い数字を書かない。**
   [時間軸_裏取り記録.md](時間軸_裏取り記録.md) に載っていないものは書かない約束である。
3. **無段階のスライダーにしない。** 理由は ADR-0006 に書いてある。必ず読むこと。
4. **「1982年がピーク」という二次情報を復活させない。** 一次統計では1964年のほうが多い。
