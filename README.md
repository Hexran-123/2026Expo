# 車窓絶景ナビ

**～絶景を逃さず見る、知る、楽しむ～**

ローカル鉄道の車窓から見える絶景を、見逃さず、その成り立ちまで楽しむためのウェブサイトです。
対象は千葉県の銚子電鉄（銚子駅〜外川駅、6.4km・10駅）。
Geoアクティビティコンテスト（G空間EXPO2027）への応募作品です。

## すぐに試す

インストールもログインも要りません。ブラウザで開くだけで使えます。

| 画面 | 開く | 向いている端末 |
|---|---|---|
| 車窓絶景ナビ | https://hexran-123.github.io/2026Expo/index.html | スマートフォン（パソコンでも可） |
| 車窓絶景ナビ（電車に乗らずに試す） | https://hexran-123.github.io/2026Expo/index.html?demo=1 | パソコン・スマートフォン |
| 絶景掲示板 | https://hexran-123.github.io/2026Expo/board.html | パソコン |

**電車に乗らずに試す**では、位置情報の代わりに時刻表どおりの電車を画面の中で走らせます。
左下の操作盤で乗る駅と向きを選んで「▶ 動かす」を押すと、発車待ち → 乗車 → 絶景の接近通知 →
成因カード → 旅の記録まで、実際に乗ったときと同じ流れを机の上で見られます
（「速さ」を ×20 にすると、銚子→外川が 1 分ほどで終わります）。

## 2つの画面

| | 車窓絶景ナビ | 絶景掲示板 |
|---|---|---|
| いつ使う | 乗っているあいだ | 旅行の前 |
| 端末 | スマートフォン | パソコン |
| 範囲 | 銚子電鉄の車窓から見える絶景 6 か所 | 銚子エリア全体の掲示スポット 25 件（路線外も含む） |
| 地図 | 標高と陰影から描き起こした平面のイラスト地図 | 斜めから見る立体地図（回転・傾き・真上まで） |

### 車窓絶景ナビでできること

- **左右どちらの窓かを知らせる。** 絶景スポットに近づくと、画面上部に
  「まもなく ヤマサ醤油工場／右の窓／あと 40 秒」と出し、短く振動します。
  同じ場所でも上りと下りで左右は逆になるので、進行方向を判定して片側だけを案内します。
- **操作しなくても切り替わる。** 駅に着いたこと・電車に乗ったことを、位置と速度と線路との位置関係から自動で判定し、
  降りる駅に着けば旅の記録に切り替わります。駅では次の発車時刻と、これから来る絶景がどちらの窓かを出すので、
  座る側を決めてから乗れます。
- **電波が途切れても止まらない。** 位置情報が途切れたら、直前の速度と経過時間から現在位置を推定し、最大 60 秒まで通知を続けます。
- **遅れが分かる。** 自分の位置と時刻表を照らして、乗っている列車が何分遅れているかを出します。
- **通り過ぎたあとに「なぜこの風景なのか」を読む。** 通過すると成因カードがせり出し、
  地形・気候・産業から、その風景ができた理由を数コマで読めます。
- **その日の天気に合わせる。** 気象庁の予報から、よく見えそうな絶景を地図上で強調します。
- **旅の記録を残す。** 降りたあと、通過した絶景・撮った写真・ひとことを 1 枚の画像にまとめ、保存や SNS への共有ができます。
- **ほかの路線にも使える。** 路線・時刻表・絶景スポットのデータを差し替えるだけで動きます。
  実演として東京メトロ有楽町線も選べます。ほぼ全線が地下のため、車窓からは見えない土地の成り立ちを
  「足もとの地理」として案内します。

### 絶景掲示板でできること

- **立体地図の上に写真が刺さる。** 地形の高低差が分かる斜め視点の地図に、掲示スポットの写真をピンとして並べます。
  「駅」「絶景」で絞り込めます。
- **写真を投稿できる。** 乗客が撮った写真を投稿でき、制作者が目で見て確かめたあとに掲示されます。
- **時間軸で土地の変化を見る。** 「時間」タブで 1923 年／1981 年度／現在を切り替え、
  銚子漁港と愛宕山の採石場の移り変わりを、年代ごとの空中写真や旧版地形図とともに読めます。
- **出典を一覧できる。** 「出典」タブに、この画面が使っている地図・資料・論文・写真をまとめてあります。

## 地理空間情報の活用

| 使っているもの | どう使っているか |
|---|---|
| 国土地理院 標高タイル（DEM5A・DEM10B） | 標高を 6 段に塗り分け、台地と低地が一目で分かる地図を描く。掲示板では高さとして立ち上げる |
| 国土地理院 陰影起伏図 | 地形に立体感を与え、切通しや台地の縁を読み取れるようにする |
| OpenStreetMap の線路・駅 | 現在地を線路の上に対応づけ、進行方向・絶景までの距離・左右どちらの窓かを計算する |
| 時刻表 × 現在地 | 乗っている列車を推定し、遅れを求める |
| 気象庁の天気予報 | 天気に合う絶景を地図上で強調する |
| 国土地理院の空中写真・旧版地形図（今昔マップ） | 港や採石場の、年代ごとの変化を見せる |
| 国土地理院 地名検索・OpenStreetMap | 掲示スポットの座標を決め、出どころと確からしさを1件ずつ記録する |

成因カードと時間軸の解説は、制作チームが現地調査と文献をもとに書いています。

## 利用者の情報の扱い

- ログインはありません。名前もメールアドレスも預かりません。
- 乗車中の位置情報は端末の中だけで使い、サーバーへは送りません。
- 撮った写真は端末の中に保存されます。外へ出るのは、利用者が「絶景掲示板に出す」を選び、同意の確認を済ませたときだけです。
- 投稿する写真は、送る前に端末側で撮影地点などの情報（EXIF）を消し、長辺 1600px に縮めます。
- 投稿された写真は、2027 年 4 月 30 日にすべて削除します。

## 技術構成

- HTML・CSS・JavaScript だけで作っています。フレームワークもビルド工程もありません。GitHub Pages で配信しています。
- 地図は地図タイルを表示するのではなく、実データから描き起こしています（車窓絶景ナビは SVG、絶景掲示板は CSS の 3D 変形）。
- 一度開いた路線の地図・時刻表・絶景スポットはブラウザに保存するので、トンネルの中でも地図と通知は動きます（Service Worker）。
- サーバーは、写真の投稿と「よく読まれている絶景」の集計だけに使います（Supabase）。つながらないときも、地図・通知・成因カード・旅の記録はそのまま動きます。
- 地図や線路のデータは `tools/` のスクリプト（Node.js、追加のパッケージなし）で、国土地理院と OpenStreetMap から作っています。

### フォルダ構成

| 場所 | 中身 |
|---|---|
| `index.html`・`js/`・`css/` | 車窓絶景ナビ |
| `board.html` | 絶景掲示板（`tools/board-template.html` から作ったもの） |
| `demo/` | 路線や動かし方を切り替えられる 1 枚にまとめた版 |
| `data/` | 路線ごとの地形・線路・絶景スポット・時刻表（`data/choshi/` が銚子電鉄） |
| `assets/`・`audio/` | 写真・図と環境音 |
| `tools/` | データを作るスクリプト |
| `supabase/` | 投稿と集計のデータベース定義 |

### 手元で動かす

データを `fetch` で読むため、ファイルを直接開くのではなく、ローカルサーバーから開いてください。

```
python -m http.server 8080
```

http://localhost:8080/ を開きます（テスト走行は http://localhost:8080/?demo=1 ）。
