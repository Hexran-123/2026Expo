# 畫面規格 ─ 現在位置マーカー

## Metadata

- 功能：車上モード（設計書 4.3）
- 畫面：地図上の現在位置マーカー（`#map-here`）と、それに付随する尾・波紋
- 狀態：**已實作・已核准**（2026-08-12。変体B ＋ 尾の案2・110m ＋ 寸法B。[mockup-decision-現在位置.md](mockup-decision-現在位置.md)）

## 目的

**揺れる車内で、視線を落とした一瞬で「いま自分がどこにいて、どちらへ進んでいるか」を拾わせる。**

いまの実装が果たせていない理由は 3 つあり、いずれも実装で確認済み。

1. **テーマ色の流用（規約違反）** ─ `.here-dot` / `.here-arrow` / `.here-halo` が `--theme-sea`（[css/style.css:1141-1159](../../../css/style.css#L1141-L1159)）を使っている。`--theme-sea` は「海と空」テーマの絶景バッジと同じ色で、銚子電鉄・有楽町線とも地図上にそのテーマのスポットがある。つまり**現在地が青いスポットの一種に見えている**。`design-system.md` は「テーマ色は地理的な意味を表す色であり、成因カードを持たないものには割り当てない」と定めており、これは規約違反でもある。
2. **止まっているときは駅と同じ形** ─ 車上モードでは矢印（`.here-arrow`）が出るので丸ではない。しかし `.here--still`（ホーム・停車中・`.here--off`）は矢印を消す（[css/style.css:1168-1170](../../../css/style.css#L1168-L1170)）ので、**丸＝駅と同じグリフに戻る**。「見失う」のはこの状態。
3. **動きを持っていない** ─ 本地図の要素はすべて静止している。`design-system.md` S4 は空いている軸を「グリフの種類・副印・動き」としており、現在地はどれも使っていない。なお**「動き」は路線カードのミニ地図（`.line-here-wave`, [css/style.css:1919-1930](../../../css/style.css#L1919-L1930)）で既に使われている**ので、作品内に前例がある。

## 版面配置

現在位置は独立した画面ではなく、地図（`#map`）の上に重なる 3 つの層で構成する。**置き場所は動かさない**（設計書 4.1）。

- 主要區域：`#map-here`（現在地そのもの。にじみ・白の輪・墨の芯・進行方向の矢印・波紋）
- 次要區域：尾（通ってきた側の線路。`#map-route` に足す `<path>` 1 本）
- 導覽：なし（現在地は選べない。`pointer-events: none`）
- 動作：なし（追従の ON/OFF は既存の `.reset-view` ボタンが持つ）

## 狀態

| 狀態 | 必要行為 | 空狀態／錯誤文案 | 驗證方式 |
|---|---|---|---|
| 預設（車上・走行中） | 墨色の芯＋白の輪＋進行方向の矢印＋尾。追従中は地図が現在地を追う | ─ | ブラウザ螢幕截圖（3 変体すべて） |
| 停車中・ホーム（`.here--still`） | 矢印を出さない（向きが決まっていないため）。波紋を出す。**尾は残す**（通ってきた道は確定しているため） | ─ | 螢幕截圖（変体ごとの「停車中」枠） |
| 線路から離れている（`.here--off`） | 受け取った緯度経度そのものに置く。輪郭を破線に。**尾は出さない**（通ってきた道が分からないため）。にじみを広げる | ─ | 螢幕截圖（変体ごとの「離れている」枠） |
| 載入中（測位待ち・許可待ち） | マーカーを出さない（`along === null` で `hidden`、[js/main.js:1976-1980](../../../js/main.js#L1976-L1980)）。位置を偽らない | 通知帯側の担当。現在地は何も出さない | コード確認 |
| 位置が古い（`DEAD_RECKON_LIMIT_MS` 超過） | マーカーを消す（[js/main.js:2458-2462](../../../js/main.js#L2458-L2462)）。尾も一緒に消す | ─ | コード確認 |
| 停用（乗車前モード） | 出さない。現在地は車上モードだけの表示（設計書 4.3） | ─ | コード確認 |
| 權限不足（位置情報の許可なし） | 出さない。許可を求める案内は既存の導線が持ち、地図には何も置かない | ─ | コード確認 |
| 濃い地形の上（`--land-45`） | 芯・尾ともに読めること。**3 変体の分かれ目**なので必ず確認する | ─ | 螢幕截圖（変体ごとの「濃い地形」枠） |
| `prefers-reduced-motion: reduce` | 波紋を出さない。墨色・白の輪・尾だけで見分けがつくこと（**動きに依存させない**） | ─ | 螢幕截圖（OS 設定を切り替えて） |
| 行動裝置版（430px 幅） | マーカーは `.scalable` により画面上の大きさが縮尺によらず一定。尾の太さも同様に扱う | ─ | 螢幕截圖 |

## 互動

| 動作 | 觸發條件 | 結果 | 失敗情境 |
|---|---|---|---|
| 位置の更新 | GPS の測位ごと（`showHere`） | 芯・矢印・尾のダッシュ・尾のグラデーション端点を書き換える | 尾の端点だけ更新し忘れると、尾が前回位置に取り残される |
| 拡大・縮小 | ピンチ／ダブルタップ | `.scalable` が `--k` を打ち消し、画面上の大きさを保つ。**尾の太さも同じ扱いにする** | 尾に `.scalable` を掛け忘れると、拡大時に尾だけ太る |
| 走行中→停車 | `mode` が `車上` 以外へ | 矢印が消え、波紋が始まる | 波紋が走行中も出続けると、動くものが二つになり酔う |
| 線路から外れる | 線路から 30m 超（`Onboard.ON_ROUTE_METERS`） | 破線に変わり、尾が消える | 尾を消し忘れると「線路の上を通ってきた」と嘘をつく |

## 確定した寸法（2026-08-12 核准。変えるときはここも直す）

数字は SVG のユーザー座標。`.scalable` が `--k` を打ち消すので、**画面上の大きさは縮尺によらず一定**。

| 部品 | 寸法 | 置き場所 |
|---|---|---|
| 芯 `.here-dot` | 半径 9.5、白フチ 6（`.here--off` のときだけ塗りを白に反転） | [index.html](../../../index.html) / [css/style.css](../../../css/style.css) |
| 外の墨の縁 `.here-rim` | 半径 13.5、太さ 1.8（`.here--off` では出さない） | 同上 |
| にじみ `.here-halo` | 半径 24（`opacity` は 走行中 0.12 ／ `--still` 0.09 ／ `--off` 0.08） | 同上 |
| 矢印 `.here-arrow` | `M0,-26 L10,-15 L-10,-15 Z`（先端 26・底辺 15・幅 10）。墨塗り＋白フチ 2.5 | 同上 |
| 波紋 `here-pulse` | 半径 13 → 34、2.2s、`opacity` 0.55 → 0 | 同上 |
| 尾の長さ `TAIL_METERS` | 110m | [js/main.js](../../../js/main.js) |
| 尾の太さ | 白 20px・墨 28px（ともに `× --k`） | [css/style.css](../../../css/style.css) |
| 芯（`.here--off`） | 半径 12・太さ 4.5・塗りは白に反転・破線 `8.4 4.17` | 同上 |

**`.here--off` の破線には条件が 2 つある。**
(a) 周長（半径 12 なら 75.4）を**割り切る**刻みにする。割り切れないと、輪の閉じ目にだけ短い破線が残って傷に見える。
(b) 破線 1 本の長さを**線の太さの 2 倍近く**に保つ（8.4 ÷ 4.5 ＝ 1.9）。ここを詰めると破線が正方形に近づき、輪ではなく**歯車**に見える。寸法を縮めた直後、半径 9.5・太さ 6 のままだったときに実機でとげの生えた塊に見えたのがこれ（[実装-線路から離れている.png](mockups/shots/実装-線路から離れている.png)）。

`.here--off` だけ芯を走行中より**大きく**するのは、「位置そのものに幅がある」ことを大きさで伝えるため。半径は CSS の `r` で当てている（`here-pulse` の波紋も同じ書き方に依存している）。

**矢印は芯の外に出す。** 底辺 15 に対し芯の外側は 12.5。芯を墨のベタ塗りにした以上、矢印を芯に重ねると同じ墨どうしが溶けて「しずく」の形にしか見えない（実機で確認済み）。

**印は駅の印（画面上 7px の白丸）より確実に大きく保つ。** 同じくらいになると「駅にいるのか自分がいるのか」が読めなくなる。これが小さくする側の下限。

## 視覚驗收標準

- テーマ色（`--theme-*`）を**一切使わない**。現在地が絶景スポットの一種に見えないこと。
- `--land-0`（#E2EACB、最も淡い）と `--land-45`（#C29A5A、最も濃い）の**両方の上で芯が読める**こと。
- `.here--still` のとき、駅の丸（`.station-dot`）と**重なっても見分けがつく**こと。
- 波紋を止めた状態（`prefers-reduced-motion: reduce`）でも、上記がすべて成立すること。**動きは補強であり、依存先ではない。**
- 尾は線路と同じ形をなぞり、**線路以外の新しい線を地図に増やさない**こと。
- 色彩・字體・間距・圓角・陰影は `design-system.md` の design token から取り、孤立した hex を書かないこと。
