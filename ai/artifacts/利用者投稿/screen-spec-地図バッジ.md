# 畫面規格 — 地図上の投稿スポット

## Metadata

- 功能：利用者投稿（絶景スポットの投稿）
- 畫面：地図画面（乗車前モード）の絶景スポットバッジ
- 狀態：草稿（mockup 未核准）

## 目的

地図を見ている人が、**タップする前に**「この点を押したら物語が読めるのか、写真が出るだけなのか」を判別できるようにする。

官方スポット（6 件）は成因カードを持ち、接近通知を鳴らす。投稿スポットは写真と名前だけで、成因カードを持たず、通知も鳴らさない。この差が見た目に出ていないと、作品の核である成因カードの価値が投稿に薄められる。

## 版面配置

- 主要區域：SVG 地図（既存）。バッジはアンカー点＋リーダー線＋バッジ本体の 3 部品（既存構造を踏襲）。
- 次要區域：下の帯のテーマ絞り込み。変体 C のみ、ここに投稿レイヤーのトグルを 1 つ追加する。
- 導覽：変更なし。
- 動作：バッジをタップ → 官方は既存の下敷き（4.1）／投稿は写真＋名前のみの簡易下敷き。

## 狀態

| 狀態 | 必要行為 | 空狀態／錯誤文案 | 驗證方式 |
|---|---|---|---|
| 預設 | 官方スポットは常に表示。投稿は変体により常時／トグル依存 | — | 螢幕截圖 |
| 載入中 | 投稿の取得中は官方スポットだけ先に描く。投稿の遅延で地図を待たせない | 表示なし（黙って待つ） | 螢幕截圖 |
| 空狀態 | 投稿が 0 件（公開直後・展示時に想定される既定状態） | 変体 A/B：何も出ない。変体 C：トグルを押すと「まだ投稿はありません」 | 螢幕截圖 |
| 錯誤 | Supabase 到達不可・タイムアウト（3 秒） | **エラーを出さず、投稿レイヤーごと出さない**（設計書 9.3 のオフライン方針に合わせる） | 螢幕截圖 |
| 停用 | 投稿機能の終了後（2027-04-30 以降） | レイヤーごと出さない | 螢幕截圖 |
| 權限不足 | 該当なし（閲覧に権限は要らない） | — | — |
| 行動裝置版 | これが既定。バッジの押せる範囲は 48px を保つ（設計書 4.1） | — | 螢幕截圖 |

## 互動

| 動作 | 觸發條件 | 結果 | 失敗情境 |
|---|---|---|---|
| 官方バッジをタップ | 常時 | 既存の下敷き（名前・場所・テーマ・ひとこと・車窓側・季節） | 変更なし |
| 投稿バッジをタップ | 投稿が表示されているとき | 簡易下敷き（写真・名前・投稿日）。**車窓側と通知は出さない**（検証されていないため） | 画像取得失敗時は名前のみ |
| 投稿トグル（変体 C のみ） | タップ | 投稿レイヤーの表示／非表示。状態は localStorage に保存 | — |
| 接近通知 | 官方スポットのみ | 通知帯＋振動 | 投稿スポットでは**鳴らさない** |

## 設計系統對照

- 用到的既有 design token：`--theme-terrain` / `--theme-farm` / `--theme-industry` / `--theme-sea`、`--land-0` / `--land-16` / `--land-32`、`--water`、`--rail`、`--station`、`--panel`、`--ink`、`--ink-soft`、`--radius`
- 用到的既有元件：絶景スポットバッジ（`.spot` / `.spot-badge` / `.spot-glyph` / `.spot-anchor` / `.spot-leader` / `.spot-label`）、テーマチップ（`.theme-chip`）、半透明バー（`.bar`）
- 本畫面新做的元件：**投稿スポットバッジ**（変体により円形／副印つきひし形）。変体決定後に `design-system.md` の元件庫 inventory へ登記する。変体 C を選ぶ場合は**投稿レイヤートグル**も新規元件として登記が必要。

## 既存の視覚語彙との衝突（重要）

不透明度・彩度の軸はすでに埋まっている。投稿の区別にこれらを使ってはならない。

| 既存の表現 | 場所 | 意味 |
|---|---|---|
| `opacity: 0.12` | `css/style.css:271` | テーマ絞り込みで非表示 |
| `opacity: 0.7` + `saturate(0.35)` | `css/style.css:366` | 天気が味方しない |
| `stroke: #E8B84B` | `css/style.css:361` | 天気が味方する |
| `opacity: 0.55` + 輪郭のみ | `css/style.css:1227` | テーマチップ非選択 |

空いている軸は **形**・**グリフの種類**・**副印**・**レイヤーの有無** の 4 つ。変体はこの範囲で作る。

## 視覺驗收標準

- 文字が手機版で截斷されない。
- 官方と投稿が、名前を読まずに（アイコンだけで）区別できる。
- 投稿バッジが駅ドット（`.station-dot`）と混同されない。
- 色彩・字體・間距・圓角・陰影はすべて `design-system.md` の token から取る。
- 投稿にテーマ色を割り当てない（テーマ色は地理的な意味を表す色＝設計書 5.4）。
