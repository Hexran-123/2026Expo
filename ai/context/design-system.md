# 設計系統（Design System）

由 Epic 0「專案設置」的「UI 設計系統」User Story 分五階段（框架 → 風格 → design token → 元件庫 → 版面）逐步填寫。**這份文件是後續所有功能 Epic 做 UI 時的單一事實來源**：任何前端任務開工前都要先讀它，能用既有 token／元件就必須用；缺的元件要照既有風格補做並登記回這裡（見 `ai/skills/project-kickoff.md` 步驟 6 與 `ai/skills/ui-mockup-gate.md`）。

狀態：S1・S2・S3・S4 は既存実装（設計書5.3/5.4章、ADR、css/style.css）から棚卸し済み。S5 は機能Epic側でPC向けレイアウト等を確定次第、追記する。

## S1 底層框架

- UI 框架：なし（素の HTML / CSS / JavaScript）
- 元件庫策略：自建（既製UIライブラリは使わない）
- 樣式方案：素のCSS（`:root` カスタムプロパティによるトークン化。ビルド工程なし）
- 選定理由：画面数・状態数が少なく、フレームワークが解決すべき問題が発生しないため（[ADR-0002](../../docs/adr/0002-フレームワークとサーバーを持たない.md)）。地図もタイルではなく自作SVGイラスト（[ADR-0001](../../docs/adr/0001-地図はタイルを使わず自作イラストとする.md)）。
- 人工核准：ADR-0001/0002として既に確定済み（2026年7月時点、コミット 75acc9f 以前）

## S2 風格方向

- 選定的 style tile：地図イラスト＋半透明白パネルのオーバーレイUI（設計書4章）
- 色彩情緒：土地の質感に根ざした落ち着いた自然色（台地の緑、畑の黄土、醤油樽の紺、海の青）。原色を避け、テーマ＝地理的意味を色で伝える。
- 字體個性：本文は Hiragino Kaku Gothic ProN / Yu Gothic / Noto Sans JP 等のシステム標準ゴシック。装飾書体は使わない（車内で瞬時に読める可読性優先）。駅名（`.station-label`）だけは丸みのあるUDフォント（Hiragino Maru Gothic ProN / BIZ UDPGothic）を先に置き、角ゴシックより柔らかく地図に馴染む見た目にする（2026-08-04、ユーザーFBにより変更）。
- 圓角／陰影傾向：大きめの角丸（14px基調）＋すりガラス風の半透明パネル（`backdrop-filter: blur`）。影は柔らかく低コントラスト。
- 密度：ゆったり（揺れる車内で押し間違えないよう、タップ領域は最小44px）。
- 亮／暗模式：ライトのみ（暗モード非対応。地図は常に明るい配色で地形が読めることを優先）。
- 参考產品：なし（既製アプリの模倣ではなく、路線固有の地形・産業データから起こしたオリジナルイラスト。[ADR-0001](../../docs/adr/0001-地図はタイルを使わず自作イラストとする.md)）
- 人工核准：設計書5.3/5.4章として既に確定済み

### Semantic Token

| Token | 對應 primitive | 用途 |
|---|---|---|
| `--panel` | 半透明白 | 上部バー・下部バー・reset-viewボタンの背景（すりガラス） |
| `--ink` / `--ink-soft` | 文字色 | 本文／補助文字 |
| `--chip-color` | テーマ色（JS側で `--theme-*` を代入） | テーマチップ・下敷きの見出しバッジの色 |
| `--card-color` | テーマ色 | 下敷き（`.card`）の `.card-theme` バッジ背景 |
| `--radius` | `14px` | パネル全般の角丸基準値 |

### 實際 token 檔位置

- 専案內真實 token 檔路徑：`css/style.css` の `:root`（1-41行）。フレームワーク非採用のため、これが唯一のトークン定義場所。
- 人工核准：既存実装として2026年7月時点で確定済み。ただし上表のtype scale・spacing scaleの「既知ギャップ」はPC向けレイアウトEpicで正式なscaleに整理する候補（新規決定が必要なため、そのEpicの中で人工核准を取る）。
