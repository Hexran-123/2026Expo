# 設計系統（Design System）

由 Epic 0「專案設置」的「UI 設計系統」User Story 分五階段（框架 → 風格 → design token → 元件庫 → 版面）逐步填寫。**這份文件是後續所有功能 Epic 做 UI 時的單一事實來源**：任何前端任務開工前都要先讀它，能用既有 token／元件就必須用；缺的元件要照既有風格補做並登記回這裡（見 `ai/skills/project-kickoff.md` 步驟 6 與 `ai/skills/ui-mockup-gate.md`）。

狀態：S1・S2・S3・S4 は既存実装（設計書5.3/5.4章、ADR、css/style.css）から棚卸し済み。S5 は機能Epic側でPC向けレイアウト等を確定次第、追記する。

## S1 底層框架

- UI 框架：なし（素の HTML / CSS / JavaScript）
- 元件庫策略：自建（既製UIライブラリは使わない）
- 樣式方案：素のCSS（`:root` カスタムプロパティによるトークン化。ビルド工程なし）
- 選定理由：画面数・状態数が少なく、フレームワークが解決すべき問題が発生しないため（[ADR-0002](../../docs/adr/0002-フレームワークとサーバーを持たない.md)）。地図もタイルではなく自作SVGイラスト（[ADR-0001](../../docs/adr/0001-地図はタイルを使わず自作イラストとする.md)）。
- 人工核准：ADR-0001/0002として既に確定済み（2026年7月時点、コミット 75acc9f 以前）

## S2 風格方向

- 選定的 style tile：地図イラスト＋半透明白パネルのオーバーレイUI（設計書4章）
- 色彩情緒：土地の質感に根ざした落ち着いた自然色（台地の緑、畑の黄土、醤油樽の紺、海の青）。原色を避け、テーマ＝地理的意味を色で伝える。
- 字體個性：本文は Hiragino Kaku Gothic ProN / Yu Gothic / Noto Sans JP 等のシステム標準ゴシック。装飾書体は使わない（車内で瞬時に読める可読性優先）。丸みのあるUDフォント（`--font-map`＝Hiragino Maru Gothic ProN / BIZ UDPGothic）を、角ゴシックより柔らかく地図に馴染む見た目として併用する（2026-08-04、ユーザーFBにより変更）。使い所は**駅名（`.station-label`）と、地図を見せる画面の見出し・路線名（`.line-picker-title` / `.line-card-name`）**の二つだけ。本文には使わない。
- 圓角／陰影傾向：大きめの角丸（14px基調）＋すりガラス風の半透明パネル（`backdrop-filter: blur`）。影は柔らかく低コントラスト。
- 密度：ゆったり（揺れる車内で押し間違えないよう、タップ領域は最小44px）。
- 亮／暗模式：ライトのみ（暗モード非対応。地図は常に明るい配色で地形が読めることを優先）。
- 参考產品：なし（既製アプリの模倣ではなく、路線固有の地形・産業データから起こしたオリジナルイラスト。[ADR-0001](../../docs/adr/0001-地図はタイルを使わず自作イラストとする.md)）
- 人工核准：設計書5.3/5.4章として既に確定済み

### 視覚チャネルの割り当て（新しい表現を足す前に必ず読む）

不透明度と彩度の軸は**すでに埋まっている**。新しい区別をこれらで表そうとすると、既存の意味と衝突する。

| 表現 | 場所 | 意味 |
|---|---|---|
| `opacity: 0.12` | `css/style.css:271` | テーマ絞り込みで非表示 |
| `opacity: 0.7` + `saturate(0.35)` | `css/style.css:366` | 天気が味方しない |
| `stroke: #E8B84B` | `css/style.css:361` | 天気が味方する |
| `opacity: 0.55` + 輪郭のみ | `css/style.css:1227` | テーマチップ非選択 |

| 印の大きさ 24 / 28 / 32px | テーマチップ | よく読むテーマ／ふつう／あまり読まないテーマ（[ADR-0004](../../docs/adr/0004-投稿と集計のためにサーバーを持ち、ログインは持たない.md)） |

投稿スポットの区別には **形＋レイヤーの有無** を使った（[mockup-decision-地図バッジ.md](../artifacts/利用者投稿/mockup-decision-地図バッジ.md)）。行動履歴の反映には **印の大きさ** を使った。

**まだ空いている軸は「グリフの種類」「副印」「動き」だけ**である。新しい区別を足すときは、視覚に頼らず**順序**や**文字**で表せないかを先に検討すること。揺れる車内で読む画面なので、視覚の次元を増やすこと自体に費用がかかる。

大きさを使うときの制約：**変えてよいのは印だけで、ボタンの箱（46×40）は変えない。** 箱ごと伸縮させると隣のチップがずれ、「置き場所を二度と動かさない」という設計書 4.1 の原則を破る。段階は 3 つに限る（連続に変えると不具合に見える）。

なお**テーマ色は地理的な意味を表す色**であり（設計書5.4）、成因カードを持たないもの（投稿スポット等）には割り当てない。
